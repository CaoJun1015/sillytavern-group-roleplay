# NPC 状态与内心面板

## 安装

将本目录的 `manifest.json`、`core.js`、`worldbook-preset.js`、`index.js`、`style.css` 放入 SillyTavern 的 `public/scripts/extensions/third-party/npc-status-panel/`，刷新页面。当前仓库使用外层目录保存任务书；发布可安装仓库时以本目录作为仓库根目录。

## 使用

先在 SillyTavern 打开原生单聊或群聊，点击右侧“角色状态”。群聊可切换成员；“编辑状态栏”可添加当前聊天共享的字段，分别填写角色值。每个聊天的字段和状态独立保存到 `chat_metadata.npcStatusPanel`。旧 `plainGroupRoleplay` 数据不会迁移。

当群聊成员恰好为七月、小乔、岚姐，且绑定或全局启用 `熟女密聊群-公共世界书` 时，空状态栏自动建立专属字段：群内信任、留群态度、群规与边界、济南日常、婚姻处境、真实资料、身体隐私。已有字段的聊天可在查看页点击“补全公共世界书状态栏”；补全只增加缺失字段，保留已有编辑。所有值初始未知，身体隐私仍须逐角色确认成年，婚姻、身份与身体字段按证据或手动剧情节点解锁。未匹配的聊天继续使用通用状态栏。

要在另一个三人群聊手动切换状态栏：先切换到那个聊天，再打开“角色状态”，点击“公共版”或“背德版”。这只修改当前聊天的状态栏；剧情世界书仍须在 SillyTavern 的世界书设置中绑定到该聊天，或全局启用。每个聊天的状态记录彼此独立，切回旧版时原有手动记录仍在。

绑定 `熟女密聊群-背德推进世界书` 的空聊天会自动启用背德版。它从三份背德版角色卡和世界书建立群内信任、留群态度、群规与边界、关系档位、私聊状态、深夜在场，以及七月的规则松动、岚姐的照顾与需求、小乔的玩笑与认真；婚姻牵绊、线下见面、离城线索、亲密风险逐步解锁。关系档位以 `0·围观者` 为起点；其他值初始未知。亲密风险还须先逐角色确认成年。角色卡中的秘密不会预填到玩家可见状态栏。

字段可选数值、描述或两者；数值为 0–100，与解锁进度无关。隐藏字段分别配置“部分了解”和“完全了解”的关键词、字段数值阈值或剧情节点。剧情节点在编辑页手动标记。成人字段只有勾选该角色“已明确确认成年人”后才能启用；默认不创建成人字段，其描述只接受玩家录入。

基础字段自动提取只识别回复或该发言者可见思考中独立成行的明确写法，例如 `心情：犹豫`、`位置：茶馆`、`信任度：62｜愿意多说一些`。其他 NPC 只能由公开回复中带姓名的明确写法更新，例如 `洛安的心情：紧张`，不会推测未发言角色的内心。证据不足时显示“未知”。基础字段提取不发起额外模型请求；群聊生成时会删去发现的其他角色私有片段，仍含私有片段的请求会被拦截。

每条已完成的非空回复都会更新该角色的“最近公开回复摘录”和更新时间。三位角色在玩家发言后的新回复保存确认时，会单独调用当前模型，依据该角色和玩家的最近对话生成一句“内心心声”；此内容是模型推测，单独存入当前聊天状态，不写入群聊正文。面板可为已有对话点击“根据最近对话生成心声”，不贴切时点“清除推测”。开场白和空白正文不会生成心声；生成会额外消耗一次模型请求。三位角色的身材参数在面板中作为角色设定资料显示，不表示剧情中玩家已知。

背德版角色卡的单聊会自动建立关系档位字段。每轮确认保存后，同一次模型分析还会从该角色自己的回复提取心情、关系、位置、亲密后状态、档位与关键节点；每项须附能在原回复中找到的证据。档位自动推进最多两级，已确认的亲密节点可以补足漏掉的档位，自动档位不会倒退；人工编辑仍可纠正。静态身体参数仍来自角色卡；身体栏会根据已确认的内射节点显示事后状态，不把风险当作已怀孕。旧聊天可在“当前状态”分析最近 6 条角色回复。全部有效关键节点保存在当前聊天元数据中，面板默认收起节点列表，点击标题可展开并查看全部；重新分析不会删除旧节点，编辑或重生成原回复时对应节点会撤销。每 12 条角色回复生成一次不额外调用模型的简短关系摘要，下一轮单聊只注入摘要、当前档位和少量近期节点；群聊不会注入私聊记忆。每轮状态分析会额外消耗一次模型请求，证据不足的字段保持未知。

保存时使用 SillyTavern 的聊天保存接口，并从服务器回读状态栏修订号确认。未确认时面板提示“未保存”。编辑、删除、重生成、切换候选后会按当前有效消息重算自动状态，手动编辑按时间保留。

## 检查

```sh
node --test test/core.test.js
node --check index.js
```

人工验收需检查单聊、三人群聊、375 px 屏宽，以及模型请求中是否混入其他角色的私有思考。无可见思考的模型不会自动提供内心描述；复杂自由文本不做语义猜测。
